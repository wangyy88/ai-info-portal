# 人工智能发展历程

## 早期发展 (1950s-1960s)

人工智能的概念最早可以追溯到1950年，当时英国数学家阿兰·图灵发表了题为《计算机器与智能》的论文，提出了著名的“图灵测试”。1956年，在达特茅斯会议上，“人工智能”这一术语被正式提出，标志着AI作为一个独立研究领域的诞生。

### 重要里程碑

| 年份 | 事件 |
|------|------|
| 1950 | 图灵发表《计算机器与智能》，提出图灵测试 |
| 1956 | 达特茅斯会议召开，AI领域正式确立 |
| 1958 | 约翰·麦卡锡发明Lisp编程语言 |
| 1965 | ELIZA程序首次实现自然语言处理 |

## AI寒冬时期 (1970s-1980s)

由于早期AI技术的局限性以及过高的期望，人工智能研究经历了两个所谓的“AI寒冬”时期，资金和兴趣都大幅下降。尽管如此，专家系统在此期间得到了发展。

## 复兴与发展 (1990s-2000s)

随着计算能力的提升和新算法的出现，AI开始复苏。1997年，IBM的深蓝计算机击败国际象棋世界冠军加里·卡斯帕罗夫，成为AI发展史上的重要节点。

## 深度学习时代 (2010s至今)

2010年代以来，深度学习技术的突破使AI进入新的黄金时代。AlphaGo战胜围棋冠军李世石，GPT系列模型在自然语言处理方面取得巨大进展，标志着AI进入了一个全新的发展阶段。
